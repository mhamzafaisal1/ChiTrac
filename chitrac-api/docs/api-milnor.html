GET /api/milnor/machine/overview

Returns machine overview summary rows in the same shape as the standard machine summary route. The route supports all machines or one machine, and can use today's cache, shift cache, or a custom hybrid of whole-day cache records plus session data for partial days.

Query Parameters

Parameter Type Required Description
serial integer No Machine serial. If omitted, active machines in the system are returned.
timeframe string No One of today, custom, or shift. Defaults to today.
shift integer Only when timeframe=shift Public integer shift id from config-shift.id. The matched shift document's _id is used to query totals-shift.shiftId.
start ISO 8601 date string Only when timeframe=custom Custom window start.
end ISO 8601 date string No Custom window end. Used only with timeframe=custom; defaults to now and is clamped to now if future.

Behavior

  • timeframe=today uses today's plant-local date in America/Chicago, from midnight to now, and queries totals-daily.
  • timeframe=shift looks up the shift by integer config-shift.id, uses today's occurrence of that shift in plant-local time, and queries totals-shift by entityType: "machine", shiftId, and date.
  • timeframe=custom queries whole calendar days from totals-daily and computes partial-day ranges from sessions.
  • If a daily or shift cache lookup has no machine-level record for a requested machine, the route falls back to session data for that same window.
  • A valid serial with no matching machine/data returns an empty array.

Example Requests

GET /api/milnor/machine/overview
GET /api/milnor/machine/overview?serial=90003
GET /api/milnor/machine/overview?timeframe=shift&shift=1
GET /api/milnor/machine/overview?timeframe=custom&start=2026-05-20T05:00:00.000Z&end=2026-05-21T12:00:00.000Z

GET /api/milnor/machine/details

Returns machine modal/detail payloads in the same shape as the standard machine dashboard daily cache route. The route supports all active machines or one machine, and uses the same timeframe inputs and cache/session hierarchy as /api/milnor/machine/overview.

Query Parameters

Parameter Type Required Description
serial integer No Machine serial. If omitted, detail payloads for active machines are returned.
timeframe string No One of today, custom, or shift. Defaults to today.
shift integer Only when timeframe=shift Public integer shift id from config-shift.id. The matched shift document's _id is used to query totals-shift.shiftId.
start ISO 8601 date string Only when timeframe=custom Custom window start.
end ISO 8601 date string No Custom window end. Used only with timeframe=custom; defaults to now and is clamped to now if future.

Behavior

  • timeframe=today uses today's plant-local date and builds modal data from totals-daily plus totals-hourly.
  • timeframe=shift uses today's occurrence of the requested shift and reads totals-shift rows for machine, machine-item, and operator-machine.
  • timeframe=custom uses daily cache rows for whole days and session/count data for partial days.
  • Hourly/chart-style data uses hourly cache for daily windows. Shift windows use shift aggregate rows for the shift bucket, with session/count fallback reserved for partial custom windows.
  • A valid serial with no matching machine/data returns an empty array.

Example Requests

GET /api/milnor/machine/details
GET /api/milnor/machine/details?serial=90003
GET /api/milnor/machine/details?timeframe=shift&shift=1
GET /api/milnor/machine/details?timeframe=custom&start=2026-05-20T05:00:00.000Z&end=2026-05-21T12:00:00.000Z

Example Response Shape

[
  {

      "name": "SPF3"
    },
    "currentStatus": {
      "code": 1,
      "name": "Running"
    },
    "performance": {},
    "itemSummary": {},
    "itemHourlyStack": {},
    "faultData": {
      "faultSummaries": [],
      "faultCycles": []
    },
    "operatorEfficiency": [],

    "timestamp": "2026-05-21T12:00:00.000Z",
    "sessionStart": "2026-05-21T05:00:00.000Z",
    "sessionEnd": "2026-05-21T12:00:00.000Z"
  }
]

Error Responses

{ "error": "Invalid timeframe" }
{ "error": "serial must be numeric" }
{ "error": "shift is required and must be an integer" }
{ "error": "Shift not found" }
{ "error": "start must be a valid ISO date string" }

GET /api/milnor/operator/details

Returns operator modal/detail payloads in the same shape as the standard operator details cache route. The route supports all active operators or one operator, optional machine narrowing with serial, and the same timeframe inputs and cache/session hierarchy as /api/milnor/operator/overview.

Query Parameters

Parameter Type Required Description
operatorid integer No Operator id. If omitted, detail payloads for active operators are returned.
serial integer No Optional machine serial filter for operator detail data.
timeframe string No One of today, custom, or shift. Defaults to today.
shift integer Only when timeframe=shift Public integer shift id from config-shift.id. The matched shift document's _id is used to query totals-shift.shiftId.
start ISO 8601 date string Only when timeframe=custom Custom window start.
end ISO 8601 date string No Custom window end. Used only with timeframe=custom; defaults to now and is clamped to now if future.

Behavior

  • timeframe=today uses today's plant-local date and builds modal data from daily/hourly cache where available.
  • timeframe=shift uses today's occurrence of the requested shift and reads totals-shift rows for operator-machine and operator-item.
  • timeframe=custom uses daily cache rows for whole days and session/count data for partial days.
  • Hourly/chart-style data uses hourly cache for daily windows. Shift windows use shift aggregate rows for the shift bucket, with session/count fallback reserved for partial custom windows.
  • A valid operator id with no matching operator/data returns an empty array.

GET /api/milnor/operator/details?operatorid=183462&serial=90003
GET /api/milnor/operator/details?timeframe=shift&shift=1
GET /api/milnor/operator/details?timeframe=custom&start=2026-05-20T05:00:00.000Z&end=2026-05-21T12:00:00.000Z
